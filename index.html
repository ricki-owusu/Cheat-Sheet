HTML TABLES

Tag Name Description
<table> Table The wrapper element for all HTML tables.
<thead> Table Head The set of rows defining the column headers in a table.
<tr> Table Row The table row container.
<th> Table Header defines a table header cell within an HTML table.
<tbody> Table Body The set of rows containing actual table data.
<td> Table Data defines a standard data cell within an HTML table.
<tfoot> Table Foot The set of rows defining the footer in a table.

CSS FONT PROPERTIES

Name Description
font-family Specifies the typeface (e.g., Arial, Times New Roman, sans-serif). Multiple font names can be provided as fallbacks.
font-size Sets the size of the text (e.g., 16px, 1.2em, medium).
font-weight Controls the boldness of the text (e.g., normal, bold, 400, 700).
font-style Applies italic or oblique styling (e.g., normal, italic, oblique).
font-variant Renders text as small caps (e.g., normal, small-caps).

CSS TEXT FORMATTING PROPERTIES

Name Description
color Sets the color of the text (e.g., red, #FF0000, rgb(255,0,0)).
text-align Aligns the text within its container (e.g., left, right, center, justify).
text-decoration Adds or removes decorative lines (e.g., none, underline, overline, line-through). This is a shorthand for text-decoration-line, text-decoration-color, and text-decoration-style.
text-transformation Controls capitalization (e.g., none, capitalize, uppercase, lowercase).
text-indent Indents the first line of a block of text.
line-height Sets the spacing between lines of text.
letter-spacing Adjusts the spacing between individual letters.
word-spacing Adjusts the spacing between words.
text-shadow Adds a shadow effect to the text.
